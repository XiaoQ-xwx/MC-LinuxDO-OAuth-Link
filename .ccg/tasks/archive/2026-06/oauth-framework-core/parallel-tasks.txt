## Implementation Specs

### config.yml
Create src/main/resources/config.yml with this content:
```yaml
oauth:
  client-id: ""
  client-secret: ""
  authorization-url: "https://connect.linux.do/oauth2/authorize"
  token-url: "https://connect.linux.do/oauth2/token"
  user-info-url: "https://connect.linux.do/api/user"
  redirect-uri: "http://127.0.0.1:8181/oauth/callback"

callback:
  host: "127.0.0.1"
  port: 8181
  path: "/oauth/callback"

security:
  state-ttl-seconds: 300
  link-code-ttl-seconds: 300
  token-expiry-skew-seconds: 60

storage:
  file: "data.yml"
```

### LinuxDoOAuthClient.java
All LinuxDO HTTP communication using java.net.http.HttpClient and Jackson ObjectMapper. Constructor takes HttpClient, ObjectMapper, OAuthConfig.
- URI buildAuthorizationUri(String state): builds auth URL with response_type=code, client_id, redirect_uri, state params
- CompletableFuture<OAuthTokens> exchangeCode(String code): POST to tokenUrl, form params grant_type=authorization_code,code,redirect_uri,client_id,client_secret. Parse {access_token, expires_in}. Calculate expiresAt = now + expires_in seconds. Non-200 throws OAuthException(TOKEN_EXCHANGE_FAILED).
- CompletableFuture<LinuxDoProfile> fetchProfile(String accessToken): GET to userInfoUrl with Bearer token header. Parse {id, username, name}. Call profile.validate(). Failure throws OAuthException(USERINFO_FAILED).
- 30s timeouts, ObjectMapper ignores unknown properties, sanitized error logging (no tokens/secrets)

### CallbackHttpServer.java
Wraps com.sun.net.httpserver.HttpServer. Constructor takes OAuthConfig and OAuthCallbackHandler. start() creates server on host:port, registers handler at callback path. stop() delays 2s. Port busy throws OAuthException(HTTP_SERVER_FAILED).

### OAuthCallbackHandler.java
Implements HttpHandler. Constructor takes PendingOAuthRegistry and LinuxDoOAuthClient. handle(HttpExchange):
1. Parse code and state from query
2. Validate state via registry
3. If invalid: HTML 400 page
4. If valid: exchange code async, fetch profile, store authorization to get linkCode
5. Return HTML 200 page showing link code
6. On failure: HTML 502 page
